# Frontend Issues & Contribution Guide

**App:** Next.js 14 + MapLibre GL + Tailwind — bilingual (EN/BN) flood intelligence console
**Live:** https://kalopathor-v2.vercel.app
**Stack:** TypeScript, next-intl, framer-motion, PMTiles, hyparquet

## Design System

All colors use CSS custom properties defined in `globals.css`:

| Token | Purpose |
|---|---|
| `--ink-0` through `--ink-3` | Background layers (darkest → lightest) |
| `--mist-1` through `--mist-3` | Text layers (dim → bright) |
| `--accent` | Primary accent (blue) |
| `--danger` | Red/alert |
| `--warn` | Amber/warning |
| `--ok` | Green/success |

Fonts: Inter (body), JetBrains Mono (data), Noto Sans Bengali (BN text).

## Issues — Ordered by Priority

### P0 — Critical (ship-blockers)

#### C1: Legend erosion color mismatch
**File:** `app/components/ui/Legend.tsx`
**Problem:** Erosion swatch shows `#f97316` (orange) but the map layer renders erosion in `#00e5ff` (cyan). The legend lies.
**Fix:** Change the erosion swatch color to `#00e5ff`.

#### C2: Popup box-shadow broken
**File:** `app/globals.css` (~line 243)
**Problem:** MapLibre popup styles reference `var(--shadow-panel-lg)` which doesn't exist as a CSS variable. The tailwind config creates a utility class `shadow-panel-lg`, not a CSS variable. Popups have no shadow.
**Fix:** Replace `var(--shadow-panel-lg)` with the actual shadow value from tailwind config, or define the CSS variable explicitly.

#### C3: DataQualityPanel labels not internationalized
**File:** `app/components/DataQualityPanel.tsx` (lines 174, 189, 216, 225, 234, 253)
**Problem:** Row labels "FFWC gauges", "SAR detection", "GLOFAS forecast", etc. are hardcoded English strings. Bengali users see English labels in this panel.
**Fix:** Move all 6 labels to `messages/en.json` and `messages/bn.json`, use `t()` calls.

#### C4: Approval page is a visible stub
**File:** `messages/en.json` (`approval.stub`, `approval.description`)
**Problem:** The approval page shows "Approval flow · stub" and "Analyst review workflow for CAP emission is not built yet." This is visible to users navigating the app.
**Fix:** Either hide the `/approval` route entirely (remove from nav), or build the approval flow. Hiding is the quick fix — add a redirect to `/operations` in `app/[locale]/approval/page.tsx`.

### P1 — High (visual quality)

#### H1: Hardcoded model metadata in VoiceSummary
**File:** `app/components/ActionCard.tsx` (~line 447)
**Problem:** VoiceSummary text hardcodes `d3v4.2`, `τ=0.5`, and `1,199` polygons. If the model updates, this text is stale.
**Fix:** Read from `ops_meta.json` (already fetched as `opsMeta` in OperationsConsole) and pass as props.

#### H2: Off-token colors in ActionCard
**File:** `app/components/ActionCard.tsx` (lines 171, 307, 311, 432)
**Problem:** Uses raw hex colors `#fecaca` and `#fca5a5` instead of design tokens. These are light reds that don't match the token system.
**Fix:** Replace with `text-danger/60` or `text-danger/40` (Tailwind opacity modifiers on the `--danger` token).

#### H3: TimeScrubber hardcodes English locale
**File:** `app/components/TimeScrubber.tsx` (line 28)
**Problem:** `shortDate()` function uses `'en'` locale for date formatting. Bengali users see English dates.
**Fix:** Accept locale from `useLocale()` (next-intl) and pass to `toLocaleDateString()`.

#### H4: DARK_BG duplicates --ink-0
**File:** `app/components/OperationsConsole.tsx` (line 62)
**Problem:** `const DARK_BG = '#070b12'` duplicates the `--ink-0` CSS variable. If the theme changes, map circle strokes go out of sync.
**Fix:** Use `getComputedStyle(document.documentElement).getPropertyValue('--ink-0')` or just use the token class.

#### H5: Legend chevron direction inverted
**File:** `app/components/ui/Legend.tsx` (lines 61-65)
**Problem:** `ChevronDown` shown when legend is open, `ChevronUp` when collapsed. Convention is the opposite.
**Fix:** Swap `ChevronDown` and `ChevronUp`.

#### H6: Basemap brightness inconsistency
**File:** `app/components/HeroMap.tsx` vs `OperationsConsole.tsx`
**Problem:** HeroMap uses `brightness-max: 0.82`, OperationsConsole uses `0.85`. Subtle but visible transition when navigating from landing to ops.
**Fix:** Extract to a shared constant in `lib/map-config.ts`.

#### H7: Duplicate i18n key
**File:** `messages/en.json` (lines 31 and 37)
**Problem:** `ops.status.livePilot` appears twice. Second value overwrites first.
**Fix:** Remove the duplicate.

#### H8: Placeholder text in DataQualityPanel
**File:** `app/components/DataQualityPanel.tsx` (~line 264)
**Problem:** "Stations above danger" row shows "not yet tracked — slot reserved" permanently.
**Fix:** Either implement (read from FFWC data) or hide the row until implemented.

### P2 — Mobile & Accessibility

#### M1: Touch targets below 44px minimum
**Files:** Multiple
- `TimeScrubber.tsx` play button: `p-1.5` → ~30px
- `Legend.tsx` toggle: `p-2` → ~32px
- `OperationsConsole.tsx` list button (line 1137): `px-2.5 py-1.5` → ~30px
- `OperationsConsole.tsx` state selector: `text-[11.5px]` with small padding

**Fix:** Increase padding to minimum `p-3` (48px) on all interactive elements. Use `min-h-[44px] min-w-[44px]` as a safety net.

#### M2: Font sizes below WCAG AA minimum
**Files:** Multiple
- `text-[9px]` in ActionCard voice label, OperationsConsole click hint
- `text-[8.5px]` in TimeScrubber
- `text-[9.5px]` in OperationsConsole

**Fix:** Minimum `text-[11px]` for any readable text. For decorative/secondary text, use `text-[10px]` with adequate contrast.

#### M3: aria-label on generic div elements
**Files:** `ActionCard.tsx`, `GaugeDrawer.tsx`, `DataQualityPanel.tsx`
**Problem:** `aria-label` on a `<div>` is not announced by screen readers. Needs `role="region"` or use `<section>`.
**Fix:** Add `role="region"` to divs with `aria-label`, or replace with `<section>`.

#### M4: No aria-valuetext on TimeScrubber
**File:** `app/components/TimeScrubber.tsx`
**Problem:** Range inputs announce raw numeric value to screen readers, not the date.
**Fix:** Add `aria-valuetext={formattedDate}` to `<input type="range">`.

#### M5: GFM toggle hidden on mobile
**File:** `app/components/ui/TopBar.tsx`
**Problem:** GFM (Copernicus flood) toggle is `hidden sm:flex` — no mobile equivalent.
**Fix:** Add to the layer switcher in WorkflowRail, or to the "More" bottom sheet.

#### M6: Freshness stats hidden on tablet
**File:** `app/components/ui/TopBar.tsx`
**Problem:** Freshness data only visible at `lg:flex`. Tablet users get no data freshness info.
**Fix:** Show condensed version at `md:flex`.

#### M7: GaugeDrawer SVG fixed aspect ratio
**File:** `app/components/GaugeDrawer.tsx` (lines 33-34)
**Problem:** `W=340, H=170` viewBox is fixed. On narrow mobile sheets the chart becomes very short.
**Fix:** Make H responsive: `H = Math.max(120, W * 0.5)` or use CSS aspect-ratio.

#### M8: Legend may truncate Bangla
**File:** `app/components/ui/Legend.tsx`
**Problem:** `w-40` (160px) width may truncate longer Bangla translations.
**Fix:** Use `w-48` or `min-w-40 w-auto max-w-56`.

#### M9: Close button aria-label hardcoded English
**File:** `app/components/OperationsConsole.tsx` (line 1506)
**Fix:** Use `t('common.close')` or equivalent.

### P3 — Polish & Tech Debt

#### T1: No loading skeletons
**Files:** `OperationsConsole.tsx`, `GaugeDrawer.tsx`, `DataQualityPanel.tsx`
**Problem:** When `opsMeta` is null, stats strip just doesn't render. Gauge chart shows "Loading…" text. No visual skeleton anywhere.
**Fix:** Add `animate-pulse` skeleton divs for stats strip, gauge chart, data quality rows.

#### T2: No error states for failed fetches
**Files:** `OperationsConsole.tsx`, `GaugeDrawer.tsx`
**Problem:** If bundle/hydro fetch fails, UI silently shows nothing. No error message.
**Fix:** Add error state with retry button: "Failed to load flood data. Tap to retry."

#### T3: HeroMap returns null on timeout
**File:** `app/components/HeroMap.tsx`
**Problem:** After 20s timeout, `setFailed(true)` returns `null` — map disappears with no fallback.
**Fix:** Return a static fallback image or gradient with "Map loading failed" text.

#### T4: prefers-reduced-motion conflicts with framer-motion
**File:** `app/globals.css` (lines 296-303)
**Problem:** Aggressive `animation-duration: 0.01ms` on all elements conflicts with framer-motion's animation system.
**Fix:** Scope the reset to non-framer elements, or let framer-motion handle its own reduced-motion via `useReducedMotion()`.

#### T5: Dead CSS token
**File:** `app/globals.css`
**Problem:** `--ink-3-solid` defined but never referenced anywhere.
**Fix:** Remove.

#### T6: console.error/warn statements (8 instances)
**Files:** `OperationsConsole.tsx` (6), `GaugeDrawer.tsx` (1), `HeroMap.tsx` (1)
**Fix:** Replace with a no-op in production, or use a structured logger.

#### T7: eslint-disable comments (3 instances)
**File:** `OperationsConsole.tsx` (lines 937, 955, 975)
**Problem:** `eslint-disable-next-line react-hooks/exhaustive-deps` — tech debt indicating dependency arrays that may be wrong.

#### T8: Magic width values
**File:** `OperationsConsole.tsx`
**Problem:** `w-[380px]` desktop panel, `max-w-[180px]` state selector, `max-h-[42vh]` layers panel.
**Fix:** Extract to named constants or tailwind theme values.

#### T9: Index keys in evidence trail
**File:** `app/components/ActionCard.tsx` (line 389)
**Problem:** `key={i}` — index keys cause React reconciliation issues if list changes.
**Fix:** Use a stable key derived from the evidence item content.

## OperationsConsole Decomposition Plan

The 1,636-line monolith should be split into:

1. **`useMap()`** hook — map init, protocol registration, style loading (~200 LOC)
2. **`useLayerManager()`** hook — layer toggle, visibility, source management (~300 LOC)
3. **`useBundleLoader()`** hook — data fetching, caching, bundle assembly (~150 LOC)
4. **`MapOverlays.tsx`** — stats strip, click hints, legend position (~200 LOC)
5. **`DesktopPanel.tsx`** — side panel with action card + gauge drawer (~150 LOC)
6. **`MobileSheets.tsx`** — bottom sheets for mobile views (~200 LOC)
7. **`OperationsConsole.tsx`** — orchestrator, reduced to ~400 LOC

## Running Locally

```bash
cd frontend
npm install
npm run dev
# Opens at http://localhost:3000
```

Requires Node.js 18+. No environment variables needed for local dev — all data is static in `public/data/`.

The freshness API reads from `public/data/freshness.json` (generated by backend `gen_freshness.py`). In local dev it returns the bundled seed data.

## Model & Data Context

- **Ops model:** d3v4.2 — EfficientNet-B0 U-Net, 6ch (VV, VH, DEM, HAND, monsoon water, CHANGE), sigmoid output, τ=0.5
- **Polygons:** 1,199 flood detection polygons from Feni 2024 replay (seeded, not live)
- **Freshness:** All data is seeded/demo except SAR acquisition timestamps (genuine Sentinel-1 dates)
- **Honesty doctrine:** Everything is labeled honestly. SEEDED/DEMO flagged amber. No claim of liveness where none exists.
